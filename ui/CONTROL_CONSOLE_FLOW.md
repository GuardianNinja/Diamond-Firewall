# Control Console Flow

Home -> Resilience Dashboard -> live state, mode, collapses, hardening passes, evidence count.

Threats -> event timeline -> policy decision -> affected resource -> quarantine state.

Policy -> profile -> ordered declarative rules -> validation -> activate (operator authorization required).

Evidence -> filters -> event record -> digest -> previous/new state -> operator/recovery action.

Ceremony -> Reset / Full Hardening / Override Approval -> confirmation -> authorization check -> action -> evidence record.

Quarantine -> resource -> reason/policy -> evidence -> Release Review -> operator approval -> release evidence.
