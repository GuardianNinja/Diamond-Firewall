# Diamond-Firewall
A security system like a living firewall that customizes for each user depending on their interactive style to have local security
# Diamond Firewall Reference v0.1

Standalone governed defensive application scaffold.

## Run
```bash
python -m pytest -q
```

The implementation is intentionally a reference model: policy, isolation, core hardening, evidence, and harness are executable, but host-level firewall enforcement and cryptographic key management require explicit platform adapters.
